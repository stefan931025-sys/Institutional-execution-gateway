# Institutional Execution Gateway & FIX Protocol Engine

A low-latency, resilient Python FIX (Financial Information eXchange) execution gateway engineered with real-time pre-trade risk controls (`RiskManager`), sequence gap management, durable session persistence (`DurableSequenceStore`), automatic network reconnection, background heartbeats (`35=D`), and automated CI/CD pipeline validation.
